# Safe_mindRwanda (SafeMind Project)

SafeMind is an Android application developed for mental health and well-being support in Rwanda.

## Overview
- **Project Name:** Safe_mindRwanda / SafeMind Project
- **Platform:** Android
- **Language:** Java
- **Build System:** Gradle (Kotlin DSL)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/iradukundanoella971-hash/Safe_mindRwanda.git
   ```
2. Open the project in [Android Studio](https://developer.android.com/studio).
3. Allow Gradle to sync and build dependencies.
4. Run the app on an Android emulator or a physical device.
